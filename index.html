بالمصري: ده عدد القطع المطلوبة من المنتج.

بالمصري: المفتاح الأساسي هنا مكوّن من عمودين مع بعض؛ نفس الطلب مينفعش يتكرر فيه نفس المنتج مرتين كسجلين.

بالمصري: بيربط تفاصيل الطلب بمنتج موجود فعلًا في جدول Product.

Q6. Customers whose orders are delivered

Question: Customers whose orders are delivered
بالمصري: اعرض Customer ID وFirst Name للعملاء الذين طلباتهم تم تسليمها.

الحل الأول — باستخدام WHERE
SELECT CustomerID, CustFirstName, OrderID, OrderStatus FROM Customer, Order WHERE CustomerID = CID AND OrderStatus = 'Delivered';

SELECT: الأعمدة المطلوب إظهارها: رقم العميل واسمه الأول ورقم الطلب وحالة الطلب.

FROM Customer, Order: نقرأ من جدول العملاء وجدول الطلبات معًا.

CustomerID = CID: يربط طلب كل عميل بصاحبه.

AND OrderStatus = 'Delivered': يضيف شرطًا ثانيًا؛ لا يعرض إلا الطلبات التي حالتها Delivered.

الحل الثاني — باستخدام JOIN
SELECT CustomerID, CustFirstName, OrderID, OrderStatus FROM Customer JOIN Order ON CustomerID = CID WHERE OrderStatus = 'Delivered';

FROM Customer JOIN Order: ادمج الجدولين باستخدام JOIN.

ON CustomerID = CID: يحدد العمودين اللذين يتم الربط عليهما.

WHERE OrderStatus = 'Delivered': يفلتر النتائج لتظهر الطلبات المسلّمة فقط.

الحلان يحققان نفس المطلوب في ورقة اللاب: الأول يكتب الجدولين مع شرط الربط في WHERE، والثاني يكتب الربط صراحةً باستخدام JOIN وON.

Q3. Product name and description using OUTPUT parameter

Question: Product name and description using OUTPUT parameter
بالمصري: المستخدم يدخل اسم المنتج مثل TV؛ استرجع الاسم والوصف واطبعهما في الرسالة المطلوبة.

الحل الأول — الطباعة داخل الإجراء
CREATE PROCEDURE GetDescription_Name @Pname VARCHAR(50), @ProductDescriptionAndName VARCHAR(100) OUT AS SELECT @ProductDescriptionAndName = ( SELECT Pname + ' and its description is ' + Pdescription FROM Product WHERE Pname = @Pname ) PRINT 'The Name of the product is ' + @ProductDescriptionAndName GO EXECUTE GetDescription_Name 'TV', OUT;

@Pname VARCHAR(50): قيمة إدخال: اسم المنتج الذي يكتبه المستخدم.

@ProductDescriptionAndName VARCHAR(100) OUT: متغير إخراج؛ OUT معناها أن الإجراء سيرجع قيمة في هذا المتغير للخارج.

SELECT @ProductDescriptionAndName = (...): خزّن نتيجة الاستعلام الداخلي داخل متغير الإخراج.

SELECT Pname + ... + Pdescription: كوّن نصًا واحدًا يجمع اسم المنتج وعبارة الوصف والوصف نفسه.

FROM Product WHERE Pname = @Pname: ابحث في Product عن المنتج الذي اسمه يساوي المدخل.

PRINT: اطبع الرسالة في نافذة Messages.

EXECUTE ... 'TV', OUT: شغّل الإجراء وأرسل TV كمدخل وOUT لتحديد متغير الإخراج. الورقة تعرض الصيغة بهذا الشكل.

الحل البديل — اطبع OUTPUT خارج الإجراء
ALTER PROCEDURE GetDescription_Name @Pname VARCHAR(50), @ProductDescriptionAndName VARCHAR(100) OUT AS SELECT @ProductDescriptionAndName = ( SELECT Pname + ' and its description is ' + Pdescription FROM Product WHERE Pname = @Pname ) GO DECLARE @p_d VARCHAR(100) EXECUTE GetDescription_Name 'TV', @p_d OUT PRINT 'The Name of the product is ' + @p_d

ALTER PROCEDURE: تعديل إجراء موجود بدل إنشاء واحد جديد.

DECLARE @p_d VARCHAR(100): إنشاء متغير خارجي لاستقبال الناتج.

EXECUTE ... @p_d OUT: تمرير المتغير كـOutput parameter ليتم ملؤه من داخل الإجراء.

PRINT ... + @p_d: طباعة الناتج بعد انتهاء الإجراء.

حل آخر موجود في اللاب — ProductDescription
CREATE PROCEDURE ProductDescription @Pname VARCHAR(20), @PDescription VARCHAR(30) OUT AS SELECT @PDescription = PDescription FROM Product WHERE PName = @Pname; PRINT 'The name of the product is ' + @Pname + ' and its description is ' + @PDescription; GO EXEC ProductDescription 'TV', OUT;

DCL. What is Data Control Language?

Question: DCL. What is Data Control Language?
بالمصري: فهم معنى DCL وعلاقته بـGRANT وREVOKE.

DCL = Data Control Language: لغة التحكم في البيانات؛ تُستخدم لإعداد صلاحيات الوصول إلى قاعدة البيانات.
GRANT: منح صلاحية لمستخدم لتنفيذ مهمة على كائن في قاعدة البيانات.
REVOKE: سحب صلاحية سبق منحها.
DDL: في وصف الملف، اللغة التي تضيف وتحذف كائنات قاعدة البيانات.
DML: في وصف الملف، اللغة التي تسترجع وتضيف وتعدّل محتوى قاعدة البيانات.

GRANT — General syntax

Question: GRANT — General syntax
بالمصري: منح صلاحية لمستخدم على كائن.

GRANT privilegeName ON objectName TO userName [WITH GRANT OPTION]

GRANT: امنح صلاحية.

privilegeName: اسم الصلاحية مثل SELECT أو INSERT أو UPDATE.

ON objectName: الكائن الذي ستطبق عليه الصلاحية، مثل جدول أو View أو Procedure أو Function.

TO userName: المستخدم الذي سيأخذ الصلاحية، أو PUBLIC.

مراجعة سريعة قبل الامتحان

  • SELECT: الأعمدة التي تريد عرضها.
  • FROM: الجدول أو الجداول التي ستقرأ منها.
  • WHERE: شرط لتصفية الصفوف.
  • JOIN / ON: ربط الجداول وتحديد أعمدة الربط.
  • IN: التحقق أن القيمة موجودة داخل مجموعة نتائج.
  • COUNT(*): عدّ الصفوف.
  • MAX(column): أكبر قيمة في العمود.
  • DISTINCT: إزالة التكرار.
  • Stored Procedure: تُنشأ بـCREATE PROCEDURE وتُشغّل بـEXEC.
  • Function: تُنشأ بـCREATE FUNCTION وتُرجع قيمة بـRETURN أو جدولًا بـRETURNS TABLE.
  • OUT: Parameter لإخراج قيمة من Procedure.
  • GRANT: منح صلاحية باستخدام TO.
  • REVOKE: سحب صلاحية باستخدام FROM.
نقطة الامتحان: لا تخلط بين RETURNS INT / VARCHAR (قيمة واحدة) وRETURNS TABLE (جدول نتائج)، ولا تنسَ شرط الربط بين الجداول في WHERE أو ON.
